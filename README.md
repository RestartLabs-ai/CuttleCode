# CuttleCode

A desktop and mobile workspace for running AI coding agents across all your projects, with powerful workflows and automation built in. Bring your own subscription for Claude Code, Codex, Cursor, and more.

**[cuttlecode.dev](https://cuttlecode.dev)**

## Download

Installers for macOS, Windows and Linux are published on the
[Releases](https://github.com/RestartLabs-ai/CuttleCode/releases/latest)
page. The desktop app updates itself from this repository.

| Platform | File |
|---|---|
| Windows | `CuttleCode-Setup-<version>.exe` (installer) or `CuttleCode-<version>.msi` |
| macOS (Apple Silicon) | `CuttleCode-<version>-arm64.dmg` |
| Linux | `CuttleCode-<version>-x86_64.AppImage` or `CuttleCode-<version>-amd64.deb` |

## About this repository

This repository hosts release artifacts only. The CuttleCode source is
not public.

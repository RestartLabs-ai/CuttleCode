# Code Command Center

A mobile-first orchestration dashboard for managing Claude Code CLI sessions
across multiple projects via real PTY passthrough.

**[codecc.ai](https://codecc.ai)**

## Download

Installers for macOS, Windows and Linux are published on the
[Releases](https://github.com/RestartLabs-ai/CodeCommandCenter/releases/latest)
page. The desktop app updates itself from this repository.

| Platform | File |
|---|---|
| Windows | `CCC-Setup-<version>.exe` (installer) or `CCC-<version>.msi` |
| macOS (Apple Silicon) | `CCC-<version>-arm64.dmg` |
| Linux | `CCC-<version>-x86_64.AppImage` or `CCC-<version>-amd64.deb` |

## About this repository

This repository hosts release artifacts only. The Code Command Center source is
not public.
